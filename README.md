## 开跑前，先把额度安排好

**“还剩多少”旁边，再放上“能用多久”。** 小时消耗、预计可用时长、均摊至重置与使用建议四张卡，把余量变成下一段工作的参考。颜色提示压力，重置时间既能看具体时刻，也能看逐位翻动的倒计时。

**卡别放到过期才想起来。** 可用数量、逐卡到期日期、剩余时间和用卡后时长参考放在一处；先到期的排前面，临期变色，72 小时 / 24 小时提醒。“去重置”直达官方页面，由你决定是否使用。积分余额与已观测消耗也一起看。

低额度、严重不足、耗尽、确认重置或恢复，各有提醒。今天 / 7 天 / 30 天的额度与积分曲线，让你回看刚才怎样消耗、何时恢复；不必守着一个百分比反复刷新。

## 谁花了 Token，哪里拖了时间，追得到

**一个总数，展开成整个 Agent 家族。** 主会话自身、子 Agent 合计、含子总计分开呈现；标题、昵称、稳定头像、模型和推理强度帮助认出每个成员，多层委派还能追到上级。

![真实交互：展开主会话与子 Agent，查看模型、强度、Token 明细与打开聊天入口](assets/v3.2.18/session-tour.gif)

输入、缓存读取、记录中存在的缓存写入、输出和推理逐项可查。发现高消耗会话，搜索标题继续找；有效线程可直接“打开聊天”回到 Codex。工具调用树图、消息构成与技能读取排行，让数字继续解释工作方式。

**等待也有线索。** 首 Token 等待和轮耗时分开看，任务耗时柱追到某一次；工具 / 命令族排行看谁花了时间，压缩记录看上下文何时整理，Agent 并行度看多少会话在同时推进。

<details>
<summary>继续追到样本、任务和工具</summary>

![真实任务耗时与工具执行排行近景](assets/showcase-20261105/analysis.jpg)

- **主会话与子 Agent 分开分析。** 今天 / 7 天 / 30 天自由切换，会话分析可前后翻时段；主会话看用户消息，子 Agent 看独立模型响应，辅助执行另列。汇总指标可展开会话、Agent、模型与项目名单，列表支持按标题搜索、继续加载。
- **Token 拆得清楚。** 缓存读取与未缓存输入分别呈现，推理是输出的一部分，不重复计入总量；推理 / 普通输出构成、已记录任务的推理强度时长占比与 faster usage 分开查看。
- **数字也交代覆盖。** 首 Token 等待和完整轮耗时摘要基于正常完成样本，悬停查看中位数、P95、有效样本、预期轮数与覆盖率；失败次数、失败率和任务停止分别统计。
- **图上的一根柱，能追到任务。** 当天按发生时间画已计时任务，标题与可读取首问帮助辨认，拖范围滑块缩放；7 天 / 30 天看日总耗时或平均耗时。压缩事件单独计时，多日可看每日压缩耗时占比。
- **工具不止一个名字。** 调用次数、完整计时的累计耗时、命令族、近期主要操作与最近会话线索一起看，分页继续查。模型 / 使用端可比较消息活动，技能排行展示识别到的 SKILL.md 读取请求。
- **并行状态有时间坐标。** 执行中数量、区间峰值、任务重叠时间与分布，主会话和子 Agent分别观察，状态以最后采样为准。

会话归属和计时依赖本机可识别记录。“打开聊天”需有效线程与本机 Codex 协议注册；技能读取不代表完整技能执行。轮耗时包含工具和等待，累计工具耗时可能重叠；任务区间重叠不等于模型请求并发。

**先看哪天特别忙，再点进去找原因。** 今天看小时变化，7 天 / 30 天看总量与构成，全年看热力日历。点选日期，汇总和会话跟着筛选；模型排行与项目用量继续回答资源花到了哪里。

今天 / 昨日对照，年度 Token、有记录天数、单日峰值、最长任务与连续使用天数，让长期使用有了轮廓。工作 / 空闲时间线把已识别任务串起来，7 天 / 30 天还能回看自然日运行占比。
