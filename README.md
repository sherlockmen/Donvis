## 下一段任务，能不能放心开跑？

只知道“还剩 30%”，很难决定接下来做什么。Donvis 把**余量、速度、预计可用时长与重置时间**放在一起，让你有依据地安排任务。

- **现在有多少。** 按账号实际返回展示额度窗口，剩余 / 已用自由切换；颜色提示压力，重置时间可看具体时刻，也可用翻页钟逐位显示天、时、分、秒。
- **按这个节奏能跑多久。** 小时消耗、预计可用时长、均摊至重置与使用建议，四张卡一起参考；消耗与均摊节奏的倍率、历史模型与强度的试用参考也能对照，悬停查看观测时段与样本依据。
- **刚才发生了什么。** 今天 / 7 天 / 30 天的额度与积分曲线，区分周期重置、已确认用卡和来源未确认的恢复；区间高低点、采样数与最近更新都有记录，图例可隐藏曲线，悬停看准确值。
- **重要时刻有人提醒。** 低额度、严重不足、耗尽、确认重置或恢复分别提示；阈值可调，不同窗口独立判断，同一周期去重。重置卡临近 72 小时 / 24 小时到期也会提醒。

## 一个任务，一群 Agent，每一份消耗都有归属

并行交给多个 Agent 很爽，跑完只剩一个总数却不够。**在 Donvis，展开一条主会话，就能看见整个 Agent 家族。**

![真实交互：展开会话家族，逐个查看子 Agent、模型、强度和 Token 明细](assets/v3.2.18/session-tour.gif)

- **主会话自身、子 Agent 合计、含子总计，三份数字分开看。** 多层 Agent 还能追到上级，避免把团队总量误认成主会话自己的消耗。
- **认得出每一个成员。** 会话标题、Agent 昵称、稳定头像、模型与推理强度一起出现；悬停汇总指标还能打开对应名单，沿归属继续追查。
- **拆到每一类 Token。** 输入、缓存读取、记录中存在的缓存写入、输出和推理各有位置；推理属于输出，不会重复相加。
- **看完统计，回到现场。** 搜索会话标题、继续加载更多记录；有效线程可直接“打开聊天”返回 Codex。辅助执行与交互会话分别呈现。

想比较主会话和子 Agent，切换范围就行。主会话看用户消息，子 Agent 看独立模型响应；前后翻查时段，模型、使用端、消息构成、工具调用矩形树图与技能读取排行，让“用了多少”继续回答“怎么用的”。

<sub>会话归属以本机可识别记录为准；技能排行统计识别到的 SKILL.md 读取，不代表完整技能执行次数。“打开聊天”依赖本机 Codex 的协议注册。</sub>

## 等了很久，终于知道时间花在哪里

![真实性能分析：按发生时间排列的任务耗时、工具和命令族排行、推理构成与上下文压缩](assets/v3.2.21/performance.jpg)

| 想追的线索 | 继续往下看 |
| --- | --- |
| **多久开始回应** | 正常完成样本的首 Token 等待、完整轮耗时中位数；悬停看 P95、有效样本、预期轮数与覆盖率。 |
| **哪次任务特别长** | 每次任务按发生时间画柱，标题与可读取的首问摘要帮助辨认；拖动范围滑块聚焦一段。7 天 / 30 天可看日汇总与平均耗时。 |
| **哪个工具花了时间** | 工具和命令族的调用次数、已完整计时的累计耗时、近期主要操作；分页继续看。 |
| **什么时候压缩了上下文** | 一次事件一根柱，保留计时依据，同样支持范围缩放；7 天 / 30 天还可看每天压缩耗时占比。 |
| **几个会话同时在跑** | 执行中数量、区间峰值、任务重叠时间与时间分布；主会话和子 Agent 分开观察。 |
| **强度和速度档怎么用的** | 推理 / 普通输出 Token 构成、各推理强度的已记录任务时长占比，单独展示 faster usage。 |

失败次数、失败率和任务停止分别统计，样本覆盖也摆在数字旁边。长耗时有证据，缺失记录有说明。

<sub>完整轮耗时包含工具与等待；累计工具耗时可能重叠。并行度统计任务活动区间，包含采样时仍执行的任务，不等于模型请求并发，状态以最后采样为准。</sub>

## 让 Donvis 住进你的菜单栏

1. **下载并安装。** [Apple Silicon / M 系列](https://github.com/sherlockmen/Donvis/releases/download/v3.2.21/Donvis-3.2.21-macOS-arm64.dmg) 或 [Intel](https://github.com/sherlockmen/Donvis/releases/download/v3.2.21/Donvis-3.2.21-macOS-x86_64.dmg)，打开 DMG，将 `Donvis.app` 拖进“应用程序”。

3. **等第一份数据到位。** 额度需要网络与有效登录；本机统计首次扫描日志，曲线随后积累。按习惯调整展示、提醒和快捷键，即可开始。

- **官方额度与本机记录各司其职。** 通过 Codex app-server 沿用已有登录联网读取额度与账号资源；Token、项目、会话与性能从此 Mac 日志建立，不代表账号所有设备。一个额度窗口就显示一个，不强制凑双窗口。未记录、未返回与零用量分别处理。
- **局域网快照当前默认开启。** 监听 4100 端口，同一网络设备无需认证即可读取，可能包含账号标签、设备名与客户端信息，不含对话正文或密钥。不需要时请在“设置 → iPhone 与局域网”关闭。
- **导出前可自行检查。** Token CSV / JSON 不含正文、账号或密钥，仍包含项目名、模型与匿名会话标识；额度历史 JSON 可能含账号标签。分享卡只保留汇总数据，诊断导出不等于自动上传。
- **记录多少，解释多少。** 性能指标依赖可识别且有计时的日志；部分详情会读取本机会话标题、首问摘要。预算只是参考比较，工具 / 技能次数并非完整行为审计。Donvis 观察与分析，不替你发任务、切模型或消耗重置卡。
